# Simple Interest Calculator

A small Bash command-line calculator that computes simple interest from a principal amount, annual interest rate, and time period.

## Usage

Run the script with Bash:

```bash
bash simple-interest.sh
```

Enter the principal, annual rate of interest (as a percentage), and time in years when prompted. The calculator reports the simple interest and total amount.

Formula: `simple interest = principal × rate × time / 100`.
